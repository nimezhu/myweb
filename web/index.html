A tiny local web server for your data files. It serves the directory you start it in (-d), lets pages list, read, write and upload files over a small HTTP API, and hosts a web app at /. This page is the default app. Replace it with -web <dir>.

Not signed in. Writing, uploading and commands need this server's access token. Open the link printed in the terminal (or press o in the terminal UI) to sign in this browser.

Files

Live listing of the root directory via GET /ls/; files open via /f/.

Write a file

POST /w/<path> with the content as the body.

Upload

POST /cmd/uploadFile (form field myFile, max 10 MB). Stored in uploads/.

API

Every endpoint returns JSON. Errors look like {"success":0,"error":"…"} with a matching HTTP status.

MethodPathWhat it does
GET/f/<path>Read a file (or directory index)
GET/ls/<dir>List a directory as JSON
POST/w/<path>Write the request body to a file (creates folders)
POST/rm/<path>Remove a file
POST/cmd/uploadFileMultipart upload into uploads/
GET/cmd/fetchUrl?url=…Fetch OpenGraph metadata for a link
GET/cmd/statusVersion, read-only and sign-in state
GET/cmd/List plugin commands
POST/cmd/<name>Run a plugin command (JSON body in, {"success":1,"result":…} out)
GET/versionServer version
WS/echoWebSocket echo (test page)
POST/cmd/stopServerStop the server (same-origin only, control page)

When the server runs with -auth, writes and commands need the access token: send Authorization: Bearer <token>, or sign in once via /?token=<token> (sets a cookie). Missing token → 401. Read-only mode (-r, or r in the terminal UI) → 403.

Plugin commands

Registered in Go with srv.RegisterCmd(name, fn, opts…) and served at POST /cmd/<name>.
